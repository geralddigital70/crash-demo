\# GeraldX - Real-Time Crash Betting Game



A full-stack, multiplayer crash betting game built with React, Node.js, and WebSockets. Players bet on a rising multiplier and must cash out before it crashes.



\## 🚀 Features



\- \*\*Real-Time Multiplayer\*\*: Watch other players bet and cash out live using Socket.IO.

\- \*\*Provably Fair\*\*: Uses cryptographic hashing to generate crash points, verifiable by the user.

\- \*\*Auto-Bet \& Auto-Cashout\*\*: Set a target multiplier and let the game play for you.

\- \*\*Live Bet History\*\*: Track your wins and losses in real-time.

\- \*\*User Authentication\*\*: Secure registration and login with JWT.

\- \*\*Password Reset\*\*: Fully functional email-based password recovery using Resend.

\- \*\*Interactive UI\*\*: Glowing canvas chart, sound effects, and a sleek dark mode design.



\## 🛠️ Tech Stack



\*\*Frontend:\*\*

\- React (Vite)

\- Tailwind CSS

\- Socket.IO Client

\- React Router DOM

\- HTML5 Canvas (for the multiplier chart)



\*\*Backend:\*\*

\- Node.js \& Express

\- Socket.IO

\- SQLite (better-sqlite3)

\- JSON Web Tokens (JWT)

\- Bcrypt.js (Password hashing)

\- Resend (Email API)



\*\*Deployment:\*\*

\- Frontend hosted on Vercel

\- Backend hosted on Render
